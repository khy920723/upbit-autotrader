# 용어 정의서

상태: 확정

| 용어 | 뜻 |
|---|---|
| 페이퍼(paper) 모드 | 실시간 시세로 가상 체결하는 모의 매매. 기본 모드 |
| signal-only 모드 | 시그널과 "냈을 주문"만 기록하는 모드 |
| 실전 점검(live-validate) | 주문을 업비트 주문 검증 API(`/v1/orders/test`)로만 보내는 모드. 체결 없음 |
| 실전(live) | 실제로 주문하는 모드 |
| live 계열 | live-validate와 live 모드 |
| 인정일 | paper 모드에서 RUNNING·PAUSED·BUY_BLOCKED 상태였던 시간의 합이 하루(09:00 KST 기준) 12시간 이상인 날. 누적으로 센다 |
| 실전 전환 게이트 | 인정일 28일 + 체크리스트 A를 지나야 실전 점검, live-validate 3일 + 체크리스트 B를 지나야 실전으로 넘어갈 수 있게 하는 제한 |
| 시그널 | LLM이 코인별로 낸 판정. positive(긍정), negative(부정), neutral(중립) |
| 확신도(confidence) | LLM이 시그널과 함께 내는 0~1 값. 임계값 이상일 때만 시그널을 쓴다 |
| 규칙 조건 | LLM 긍정과 함께 만족해야 하는 지표 조건. 1단계에서 확정 |
| 위험 한도 | 예산, 노출, 손절, 일일 손실, 주문 간격·횟수처럼 항상 우선하는 제한 |
| 손절 | 평가손실률이 설정값에 닿으면 매도 |
| 익절 | 평가수익률이 익절 단계의 발동 수익률에 닿으면 매도(선택 기능). 최대 2단계로 나눠 팔 수 있다 |
| 단계(분할) | 포지션 하나를 나눠 사거나 파는 주문 하나. 매수 최대 2단계, 익절 최대 2단계. 손절과 그 밖의 매도는 나누지 않는다 |
| 일일 손실 한도 | 하루(09:00 KST 기준) 실현 손실 합계의 상한. 닿으면 그날 신규 매수 중지 |
| 노출(exposure) | 보유 코인의 평가금액 + 미체결 매수 주문 금액 |
| 재진입 제한 | 손절 후 같은 코인의 재매수를 막는 옵션. 기본은 제한 없음 |
| 일시정지 | 신규 매수만 멈추는 상태(PAUSED). 손절·청산은 계속 |
| 긴급 정지 | "정지"(손절 포함 모든 신규 주문 중지 + 앱이 낸 미체결 주문 취소, D-069)와 "정지 후 전량 매도" 두 버튼. 손절을 유지하려면 "일시정지"를 쓴다 |
| 데이터 의심(DEGRADED) | 시세 웹소켓 끊김이나 시계 오차 때의 상태. 신규 매수를 멈추고 손절은 REST 시세로 계속 |
| 통신 불가(SUSPENDED) | 네트워크 끊김이나 418 차단으로 주문할 수 없는 상태 |
| 유의 종목 | 업비트가 투자유의로 지정한 종목. API의 `market_event.warning=true` |
| 주의 플래그 | 업비트 시장경보(주의·경고·위험). API `market_event.caution`의 항목 중 하나라도 true. 단계는 API로 알 수 없음 |
| 거래지원 종료 | 상장 폐지. 시세 웹소켓의 `delisting_date`와 공지 웹소켓 `announcement`로 감지 |
| 서브 포켓 | 업비트 계정 안의 별도 자산 공간(2026년 도입). 봇 전용 자금만 넣어 노출 상한으로 쓴다 |
| 허용 IP | 업비트 API 키에 등록한 공인 IPv4. 등록된 IP에서만 키가 동작 |
| identifier | 주문마다 앱이 붙이는 고유 ID. 재사용할 수 없고, 타임아웃 후 주문 확인에 쓴다 |
| smp_type | 자기 주문끼리의 체결을 막는 방식. 매 주문에 명시한다 |
| 슬리피지 | 주문 시점 가격과 실제 체결 가격의 차이 |
| 호가 단위 | 가격 구간별 최소 가격 단위(예: 100만 원 이상은 1,000원) |
| 최소 주문 금액 | KRW 마켓 주문 1건의 최소 금액(5,000원, API로 확인) |
| Remaining-Req | 업비트 응답 헤더. 남은 초당 요청 수(`sec`)를 알려 줌 |
| 418 차단 | 요청 한도를 반복해서 넘기면 업비트가 일정 시간 요청을 막는 것 |
| look-ahead bias | LLM이 학습 중에 미래 결과를 봤을 수 있어서 과거 백테스트 성과가 부풀려지는 문제 |
| 프롬프트 인젝션 | 외부 텍스트에 섞인 지시로 LLM 판단을 조작하는 공격. 이 앱은 뉴스 제목을 넣지 않아(D-097) 그런 입력이 거의 없다 |
| 보고서 세션 | 매매 PC에서 앱과 같은 Windows 계정으로 도는 Claude Code CLI(D-109). 코인마다 웹 검색 기반 긍정·부정 값(D-108·D-112)과 예상·결과 보고서를 낸다. [분석 보고서 세션 제안서](../03-functional/analysis-report-session.md) |
| 예상 결과 보고서 | 코인 하나에 대해 다음 결과 시각까지의 흐름을 예상하고 매수 판정을 담은 보고서. 매수 근거 전체다(D-114). 1차 예상 보고서의 입력이 되는 첫 분석 보고서는 "초본"이라 부른다 |
| 결과 보고서 | 예상 결과 보고서와 실제 흐름을 비교한 보고서. 하루 경계 KST 09:00(D-113)에 쓰고 다음 회차 예상의 입력이 된다 |
| 회차 | 예상 결과 보고서 하나와 그 결과 보고서 하나의 묶음. 코인마다 센다 |
| 매매 예상률 | 예상과 실제가 맞은 정도. 정의는 제안서 R10의 답으로 정한다 |
| Claude Code CLI | Anthropic의 명령줄 도구. `claude -p`로 비대화형 실행을 한다. 이 앱의 LLM 시그널(웹 검색, D-112)과 예상·결과 보고서(D-114)를 맡는다(D-108) |
| keyring | Windows 자격 증명 관리자에 비밀을 저장하는 Python 라이브러리 |
| ESU | Windows 10 연장 보안 업데이트. 개인용은 2027-10-12까지 |
| 자동 로그인 | 재부팅 후 암호 입력 없이 Windows에 로그인하는 설정. 무인 재개에 필요 |
| onedir | PyInstaller의 폴더형 빌드. exe와 라이브러리가 한 폴더에 들어감 |
| SmartScreen | 서명 없는 exe를 실행할 때 Windows가 띄우는 경고 |
| 결정 로그 | 사용자와 정한 결정을 날짜·근거와 함께 남기는 문서 |
