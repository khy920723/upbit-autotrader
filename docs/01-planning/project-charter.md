# 프로젝트 개요서

상태: 확정 · 관련: [요구사항 정의서](requirements.md), [로드맵](../10-management/roadmap.md), [결정 로그](../10-management/decision-log.md)

## 1. 배경

- 업비트 원화 마켓의 코인을 사람이 계속 지켜보며 매매하기는 어렵다.
- 시세·지표와 뉴스를 함께 보고 판단하는 과정을 LLM으로 자동화하되, 손실은 코드로 정한 한도 안에 묶어 두려 한다.
- 개발 과정과 결과를 공개 저장소에 남겨 포트폴리오로 쓴다.

## 2. 목적

- 선택한 최대 3개 코인을 사람 없이 자동 매매하는 Windows 데스크톱 앱을 만든다.
- 손실 상한(코인별 예산, 손절, 일일 손실 한도, 긴급 정지)을 LLM 판단과 상관없이 항상 강제한다.
- 성과는 페이퍼(모의) 실적으로 확인하고, 실전 여부는 사용자가 판단한다.

## 3. 목표와 성공 기준

| 목표 | 성공 기준 |
|---|---|
| 무인 운영 | 재부팅 후 자동 로그인 → 자동 실행 → 시작 점검 → 매매 재개가 사람 손 없이 된다 |
| 손실 상한 | 어떤 시나리오에서도 위험 한도를 넘는 주문이 나가지 않는다(테스트로 증명) |
| 주문 안전 | 타임아웃·크래시·재시작에도 중복 주문이 0건이다 |
| 투명성 | 모든 시그널의 입력·출력 원문과 주문 이유가 기록된다 |
| 검증 | 페이퍼 인정일 28일 이상 운영한 기록이 남는다 |
| 비용 | 운영 비용 0원(무료 API와 공개 저장소 CI 범위) |

수익은 목표 지표에 넣지 않는다. 어떤 로직도 수익을 보장할 수 없고, 이 앱은 투자 자문이 아니다.

## 4. 범위

- **포함:** 업비트 KRW 마켓, 최대 3개 코인, Gemini 무료 등급 시그널, 네이버·RSS 뉴스, 페이퍼·실전 점검·실전 모드, 디스코드 알림, Windows 데스크톱 실행 파일.
- **제외:** 다른 거래소, BTC·USDT 마켓, 다른 사람의 자금 운용, 앱 판매·시그널 제공, 고빈도 매매, 입금·출금, 모바일 앱, 서버 배포.

## 5. 제약

- **실행 PC:** Windows 10 22H2 64비트 데스크톱. 지원이 끝난 OS라 ESU(2027-10-12까지)에 등록하고, 그 전에 Windows 11 이전을 계획한다.
- **업비트 키:** 등록한 공인 IP에서만 동작하고 1년 뒤 만료된다. 집 IP 고정 여부를 모르므로 유동 IP를 전제로 설계한다.
- **개발 환경:** Claude Code 클라우드 세션(리눅스)에서 개발하고 .exe는 GitHub Actions Windows 러너에서 빌드한다. 클라우드 세션은 빌드 설정 파일을 수정할 수 없다.
- **공개 저장소:** 키와 개인 정보는 저장소에 절대 두지 않는다.
- **Gemini 무료 한도:** 공개되지 않고 보장되지 않는다.

## 8. 면책

이 프로젝트는 투자 자문이 아니며 수익을 보장하지 않는다. 자동매매는 버그, 장애, 급변동으로 손실이 날 수 있다. 실제 자금을 쓸지와 금액은 사용자가 스스로 판단한다.
