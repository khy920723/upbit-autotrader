# 사용자 시나리오

상태: 초안 · 관련: [화면 흐름도](../02-ux/screen-flow.md), [운영 런북](../09-operations/runbook.md)

사용자는 앱을 만든 본인 1명이다. 전제: Windows 10 데스크톱, 자동 로그인 사용, 집 IP 고정 여부는 모름.

| ID | 시나리오 | 흐름 | 관련 |
|---|---|---|---|
| UC-01 | 처음 설치 | zip 다운로드 → 차단 해제 → 압축 해제 → 실행 → 첫 실행 마법사(면책 동의, 키, 코인, 한도, 실행 설정) → 시작 점검 → paper로 시작 | FR-03, FR-05 |
| UC-02 | 평소 운영 | 사용자는 아무것도 하지 않는다. 4시간마다 시그널 평가, 1분마다 손절 점검. 체결과 일일 요약은 텔레그램으로 받는다 | FR-08, FR-10, FR-16 |
| UC-03 | 상태 확인 | 트레이 아이콘 → 대시보드에서 코인별 포지션·손익·최근 시그널 이유를 본다 | FR-18 |
| UC-04 | 재부팅(Windows 업데이트, 정전 후 복구) | 자동 로그인 → 앱 자동 실행 → 시작 점검 → 직전 모드·상태로 재개 → 텔레그램 MSG-I001 | FR-01, FR-02 |
| UC-05 | 집 IP가 바뀜 | 10분 정기 점검(JOB-14)이나 주문에서 허용 IP 오류 감지 → 매매 중지 + 텔레그램 긴급 알림(현재 IP 표시) → 사용자가 업비트 PC 웹에서 IP 추가 → 앱에서 다시 점검 → 재개. 그동안 보유 코인은 업비트 앱으로 직접 대응 | FR-21 |
| UC-06 | 키 만료 예고·만료 | 30일 전 알림 → 업비트에서 새 키 발급 → 설정에서 키 재입력. 만료되면 매매 중지 | FR-20 |
| UC-07 | 긴급 상황 | "정지"(손절 포함 모든 주문 중지 + 앱이 낸 미체결 주문 취소) 또는 "정지 후 전량 매도"(확인 창)를 누른다. 손절은 두고 매수만 멈추려면 "일시정지". 다시 매매하려면 [시작] | FR-13 |
| UC-08 | 코인 교체 | 설정 → 코인 선택에서 교체. 보유 중인 코인을 빼면 손절·청산만 계속 관리(기본), 계속 보유(손절 멈춤), 시장가 매도 중에서 고르게 한다(D-068) | FR-05 |
| UC-09 | 종목 경고·거래지원 종료 | 유의·주의 지정이나 종료 공지 감지 → 해당 코인 신규 매수 차단 + 알림 → 사용자가 보유분 처리를 결정 | FR-04, FR-10 |
| UC-10 | 실전 전환 | 인정일 28일 → 평가 화면과 체크리스트 A → live-validate 3일 이상 → 체크리스트 B와 확인 문구 → live. 업비트 서브 포켓에 소액만 둔다 | FR-12 |
| UC-11 | 새 버전 설치 | 정지 → 종료 → 새 폴더로 교체(데이터는 `%LOCALAPPDATA%`에 남음) → 실행 → 시작 점검 | NFR-12 |
| UC-12 | Gemini 한도 초과·모델 폐기 | 시그널이 중립으로 처리됨 → 연속 실패 알림 → 다음 초기화(KST 16~17시)까지 기다리거나 설정에서 모델 변경 | FR-08 |
| UC-13 | live에서 paper로 되돌림 | 실제 보유 코인이 있으면 MSG-C008: 시장가 매도 후 전환, 실보유분은 손절·청산만 계속 관리하고 전환, 취소 중 선택 | FR-12 |

## 손절 후 재진입

손절했다고 해서 그 코인의 매매를 막지 않는 것이 기본이다. 필요하면 설정에서 다음 중 하나를 고른다.

- N시간 뒤 허용(기본 24시간)
- 그날은 금지(다음 날 09:00 KST에 해제)
- 직접 풀 때까지 금지
