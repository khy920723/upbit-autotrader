# 메시지·문구 정의서

상태: 초안 · 관련: [화면 정의서](screen-spec.md), [알림 정의서](../03-functional/notifications.md), [운영 런북](../09-operations/runbook.md)

- 접두어: E(오류), W(경고), C(확인), I(정보). 중괄호 `{}`는 실행 중에 채우는 값이다.
- 문구에는 원인과 해결 방법을 함께 쓴다. 키, 토큰, 계정 정보는 문구에 넣지 않는다.
- 텔레그램 알림도 같은 ID의 문구를 쓴다.

## 오류

|---|---|---|

| MSG-E002 | 키 만료 | 업비트 API 키가 만료되었습니다. 업비트 PC 웹에서 새 키를 발급하고 [설정 → 계정·키]에서 다시 입력하세요. 그동안 자동 매매는 중지됩니다. |
| MSG-E003 | 키 무효·권한 부족 | 업비트 API 키가 올바르지 않거나 권한이 부족합니다({error_name}). 자산조회·주문조회·주문하기 권한으로 발급한 키인지 확인하세요. |
| MSG-E004 | 418 차단 | 업비트가 요청을 일시 차단했습니다(418). {until}까지 자동 매매를 멈춥니다. 반복되면 [정보 → 진단 묶음 만들기]로 금액·IP·주문 ID를 가린 파일을 만들어 이슈에 첨부하세요. 로그 원본은 올리지 마세요. |
| MSG-E005 | 429 반복 | 업비트 요청 한도에 자주 닿고 있습니다. 요청 속도를 낮췄습니다. |
| MSG-E006 | Gemini 일일 한도 소진 | Gemini 무료 일일 한도를 다 썼습니다. 이번 평가는 중립(매수 안 함)으로 처리했습니다. 한도는 매일 {reset_time}(KST)에 초기화됩니다. |

| MSG-E008 | 네트워크 끊김 | 인터넷 연결이 끊겼습니다. 다시 연결되면 잔고와 주문 상태를 확인한 뒤 재개합니다. |
| MSG-E009 | 키 저장소 오류 | Windows 자격 증명 관리자에 접근할 수 없습니다. 앱을 다시 시작하고, 계속되면 키를 다시 입력하세요. |
| MSG-E010 | 시계 오차 | PC 시계가 거래소 시각과 {skew}초 차이 납니다. Windows 설정 → 시간 및 언어 → 지금 동기화를 누르세요. 차이가 줄 때까지 신규 매수를 멈춥니다. 손절은 계속 동작합니다. |
| MSG-E011 | 시세 끊김 | {market} 실시간 시세가 {seconds}초 동안 들어오지 않습니다. 다시 연결하는 동안 신규 매수를 멈추고, 손절은 REST 시세로 계속합니다. |
| MSG-E012 | 뉴스 수집 실패 | {source} 뉴스를 가져오지 못했습니다. 다른 출처로 계속합니다. |
| MSG-E013 | 주문 거절 | {market} {side} 주문이 거절되었습니다({error_name}). {hint} |
| MSG-E014 | 주문 결과 불명·미완료 | {market} 주문이 {minutes}분 넘게 끝나지 않았습니다(결과 불명 또는 미체결). 조회해서 확인하는 중이며, 확인될 때까지 이 코인의 새 주문(손절 포함)을 보내지 않습니다. |
| MSG-E015 | 예산 하한 미달(설정 저장 거부) | 코인별 예산이 너무 작습니다. 손절한 뒤에도 팔 수 있으려면 한 번에 사는 금액이 {floor}원 이상이어야 합니다(지금 {per_entry}원). 예산을 {min_budget}원 이상으로 늘리세요. 분할 매수를 쓰고 있다면 회차 수를 줄이거나 분할 매수를 끄세요. |
| MSG-E016 | 매매 엔진 응답 없음 | 매매 엔진이 {seconds}초 동안 응답하지 않습니다. 손절이 멈춰 있을 수 있습니다. 앱을 다시 시작하세요. 다시 시작하면 거래소 기준으로 잔고와 주문을 맞춥니다. |
| MSG-E017 | 내부 오류로 매매 중지 | 앱 내부 오류({code})로 자동 매매를 멈췄습니다. 손절도 멈춘 상태입니다. 보유 코인은 업비트 앱에서 직접 확인하세요. 앱을 다시 시작해도 계속되면 [정보 → 진단 묶음 만들기]로 만든 파일을 이슈에 첨부하세요. |
| MSG-E018 | Gemini 프로젝트 확인 필요 | Gemini가 요청을 거부했습니다(403 {code}). Google AI Studio에서 프로젝트 상태(검증 필요, 무료 등급 이용 불가, 결제 필요)를 확인하세요. 확인할 때까지 LLM 평가를 멈추고 모든 코인을 중립(매수 안 함)으로 처리합니다. 손절·익절은 계속 동작합니다. |
| MSG-E019 | 실보유분 주문 불가(paper의 exit_only) | 업비트 키·IP 문제({error_name})로 실제 보유분({markets})의 손절·청산 주문을 낼 수 없습니다. 가상 매매는 계속합니다. 업비트 앱에서 보유분을 직접 확인하고, 키·IP를 고친 뒤 [다시 점검]을 누르세요. |
