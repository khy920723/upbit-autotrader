# 화면 정의서

상태: 초안 · 관련: [화면 흐름도](screen-flow.md), [메시지·문구 정의서](messages.md), [설정 항목 정의서](../03-functional/settings.md)

## 공통 규칙

- 화면 문구는 한국어, 시각은 KST, 금액은 원 단위에 천 단위 쉼표.
- 상태는 색과 글자를 함께 표시한다(색만으로 구분하지 않음).
- 키와 토큰은 입력 후 가린다(앞 4자리만 표시).
- 네트워크 작업 중에도 화면이 멈추지 않는다. 오래 걸리는 작업은 진행 표시를 띄운다.
- 오류 문구는 [메시지·문구 정의서](messages.md)의 ID를 쓰고, 원인과 해결 방법을 함께 보여 준다.
- 업비트 키 없이 paper로 운영하면: 거래지원 종료 공지(JOB-12)는 동작하지 않고, 종목 목록 3시간 갱신과 시세 웹소켓의 `delisting_date`로만 감지한다. 수수료와 최소·최대 주문 금액은 키가 있어야 `/v1/orders/chance`로 읽을 수 있으므로, 키가 없으면 공식 문서의 값(최소 주문 5,000원은 KRW 마켓 안내, 수수료 0.05%는 주문 가능 정보 API의 응답 예시)을 "추정값"으로 쓰고 화면에 표시한다. 키를 넣으면 바로 API 값으로 바꾸고 예산 하한을 다시 검사한다(제안, D-059 대기). 실전 점검 버튼은 키 검증을 통과하기 전까지 비활성이다.

## SCR-01 첫 실행 마법사

| 단계 | 입력 | 검증 | 저장 위치 |
|---|---|---|---|
| W1 환영·면책 | 면책 문구 확인, 동의 체크(필수) | 체크 여부 | 설정 파일(동의 시각) |
| W2 업비트 키 | Access Key, Secret Key, 발급일 / 안내: 봇 전용 서브 포켓에서 발급, 권한 3개만, 허용 IP 등록 / [나중에 입력] 버튼: 키 없이 paper만 가능, 실전 점검 전에 필수 | 잔고 조회. 허용 IP 오류면 현재 공인 IP 표시 | keyring, 발급일은 설정 파일 |
| W3 Gemini | API 키, 모델 ID(추천 목록에서 선택 또는 직접 입력) | 짧은 테스트 호출(무료 한도 1회 사용) | keyring, 설정 파일 |
| W4 네이버 검색 | Client ID, Client Secret | 뉴스 검색 1회 | keyring |
| W5 텔레그램(선택) | 봇 토큰, chat_id("/start 보낸 뒤 찾기" 버튼) | 테스트 메시지 전송 | keyring, 설정 파일 |
| W6 코인 선택 | SCR-03과 같음 | 1~3개, 경고 종목 불가 | 설정 파일 |
| W7 위험 한도 | 코인별 예산, 손절 %, 일일 손실 한도, 익절 %(선택), 재진입 정책(기본 없음), LLM 부정 매도(기본 끔) | 범위 검사, 예산 하한(손절 후에도 매도 가능한 금액) | 설정 파일 |
| W8 실행 설정 | Windows 시작 시 실행(기본 켬), 직전 상태로 자동 재개(기본 켬), 창 닫기 = 트레이(기본) / 자동 로그인 설정 안내 링크 | - | 설정 파일, 레지스트리(HKCU Run) |
| W9 요약 | 입력 요약(비밀은 가림) | - | - |

- 검증에 실패하면 다음 단계로 넘어가지 않는다. 예외는 W2의 [나중에 입력]과 W5(건너뛰기)다.
- 모드는 paper로 시작한다. live 계열 모드는 실전 전환 게이트를 지나야 고를 수 있다.
- W7의 기본값은 예시 값이다. 화면에 "직접 정하세요. 투자 조언이 아닙니다"를 표시한다.

## SCR-02 메인 대시보드

```text
+---------------------------------------------------------------------+
| 모드 PAPER (인정일 12/28)   상태 [실행 중]   업비트 OK  LLM OK  뉴스 OK |
| 다음 시그널 평가 14:00   오늘 실현 손익 -1,200원 / 한도 -3,000원         |
+----------------------+----------------------+-----------------------+
| KRW-BTC              | KRW-ETH              | KRW-XRP               |
| 현재가 / 24h 변동     | ...                  | [주의] 매수 차단        |
| 보유 수량, 평가손익    | 보유 없음             |                       |
| 시그널 긍정 0.78 10:00| [재진입 허용]         |                       |
| 이유 요약, 규칙 충족   |                      |                       |
| 손절선 / 재진입 상태   |                      |                       |
+----------------------+----------------------+-----------------------+
| 최근 이벤트 (시각, 등급, 내용)                                          |
+---------------------------------------------------------------------+
| [일시정지/재개] [정지] [정지 후 전량 매도] [시작]  [시그널] [거래] [설정]  |
+---------------------------------------------------------------------+
```

| 구성 요소 | 내용 | 동작 |
|---|---|---|
| 상태 줄 | 모드, 페이퍼 인정일, 매매 상태, 연결 상태(업비트·LLM·뉴스), 다음 평가 시각, 오늘 실현 손익과 한도 | 상태를 누르면 SCR-07 |
| 코인 카드 | 현재가, 24시간 변동, 보유 수량, 평균 단가, 평가손익, 최근 시그널(판정·확신도·시각·이유 요약), 규칙 충족 여부, 손절선, 경고·재진입 상태 | 카드를 누르면 그 코인으로 거른 시그널·거래 기록. 재진입 제한 중이면 [재진입 허용] 버튼(MSG-C010) |
| 이벤트 로그 | 최근 100건, 등급별 색 | 항목을 누르면 상세 |
| 일시정지/재개 | 신규 매수만 멈춤(손절은 계속) | 즉시 |
| 정지 | 신규 주문 중지 + 미체결 취소, 손절도 멈춤 | SCR-09(MSG-C001) |
| 정지 후 전량 매도 | 정지 + 보유 코인 시장가 매도 | SCR-09(MSG-C002) |
| 시작 | STOPPED일 때만 표시 | MSG-C009 확인 → 시작 점검 → RUNNING |

## SCR-03 코인 선택

- 검색창(한글명·영문명·마켓 코드), 목록(한글명, 마켓, 24시간 거래대금, 경고 배지).
- 최대 3개 선택. 유의·주의·거래지원 종료 예정 종목은 비활성으로 표시하고 이유를 보여 준다.
- 보유 중인 코인을 해제하면 MSG-C007로 계속 보유할지 시장가로 매도할지 묻는다.

## SCR-04 시그널 기록

- 표: 시각, 코인, 판정, 확신도, 상태(ok, invalid, timeout, quota, refused, error), 응답 모델, 결정(매수, 보류, 차단)과 차단 이유.
- 상세: 입력 요약(지표), 뉴스 제목 목록, 원문 응답, 규칙·위험 판단 결과.

## SCR-05 거래 기록

- 주문 표: 시각, 코인, 매수/매도, 주문 유형, 금액·수량, 상태, 이유 코드, 모드.
- 요약: 일별·전체 실현 손익, 수수료, 거래 수.
- CSV 내보내기(기간 선택). 파일에는 키나 계정 정보를 넣지 않는다.

## SCR-06 설정

- 탭: 계정·키, 코인 선택, 매매 규칙, 위험 한도, 알림, 실행·시작, 고급. 항목은 [설정 항목 정의서](../03-functional/settings.md)를 따른다.
- 위험 한도를 느슨하게 바꾸면 MSG-C006으로 확인한다. 엄격하게 바꾸는 것은 바로 적용한다.
- 키는 다시 입력만 할 수 있다. 저장된 값을 화면에 보여 주지 않는다.
- 모드를 live에서 paper로 바꿀 때 실제 보유 코인이 있으면 MSG-C008로 처리 방법을 묻는다.

## SCR-07 시작 점검 결과

- 점검 항목별 결과(통과, 경고, 실패)와 해결 방법.
- 버튼: [다시 점검], [대시보드 열기(매매는 멈춘 상태 유지)].

## SCR-08 실전 전환

- 인정일(누적 / 28일). 28일 전에는 실전 점검 버튼이 비활성이다.
- 평가 요약: [페이퍼 운영 평가 기준](../08-quality/paper-evaluation.md)의 지표.
- 체크리스트 A(실전 점검 시작 전): 키 검증 통과, 봇 전용 서브 포켓에서 발급한 키, 권한 3개만, 허용 IP가 현재 IP와 일치. 키 검증과 허용 IP는 앱이 자동 확인하고(잔고 조회·주문 조회·주문 검증 성공), 서브포켓 키 여부와 권한 3개는 사용자가 업비트 화면을 보고 확인 표시한다(서브포켓 키로는 API로 조회할 수 없음, D-048 대기).
- "실전 점검 시작" 버튼(MSG-C003).
- 체크리스트 B(실전 전환 전): live-validate 3일 이상, 매수 검증 오류 0건, 위험 한도 다시 확인, 알림 동작 확인, 긴급 정지 버튼 위치 숙지, 서브 포켓에 소액만.
- "실전 전환" 버튼(MSG-C004, 확인 문구 입력).

## SCR-09 긴급 정지 확인

- 정지: 미체결 주문 건수와 "손절도 멈춤"을 보여 주고 확인(MSG-C001).
- 정지 후 전량 매도: 코인별 보유 수량과 예상 금액을 보여 주고 확인 문구 입력(MSG-C002).

## SCR-10 트레이

- 아이콘 색: 초록(실행 중), 노랑(일시정지·신규 매수 차단·데이터 의심), 빨강(중지·오류). 마우스를 올리면 상태 글자.
- 메뉴: 열기, 일시정지/재개, 정지, 정지 후 전량 매도, 시작(STOPPED일 때), 종료(MSG-C005 확인).

## SCR-11 정보·면책

- 버전, 빌드 커밋, 라이선스(MIT), 오픈소스 고지(PySide6 LGPL 등), 면책 문구.
- 데이터 폴더 열기, 로그 폴더 열기, 진단 묶음 만들기(금액·IP·주문 ID를 가린 파일).
