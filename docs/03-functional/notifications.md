# 알림 정의서

상태: 초안 · 관련: [메시지·문구 정의서](../02-ux/messages.md), [디스코드 연동 명세](../05-integration/discord.md)

## 1. 원칙

- 채널: 디스코드 비공개 채널 `app-alarm`의 웹후크(보내기 전용, D-081)와 앱 화면. 디스코드 알림을 켜지 않았으면 화면과 로그에만 남긴다. GitHub PR·CI 알림은 다른 채널(`git-alarm`, D-075)로 간다.
- 등급: 긴급(사람 조치 필요), 경고(확인 필요), 정보.
- 초당 1건 이하로 보낸다. 몰리면 묶어서 한 메시지로 보낸다. 2000자(디스코드 메시지 본문 한도)를 넘으면 자르고, 묶을 때도 2000자 안에서 나눈다.
- 키, 토큰, 계정 정보, 잔고 총액은 보내지 않는다. 코인별 금액과 손익은 보낸다.
- PC가 꺼져 있으면 알림도 못 보낸다. 일일 요약(09:00)이 오지 않으면 앱이 멈췄다는 신호로 본다.

## 3. 설정

- 등급별로 켜고 끌 수 있다. 긴급은 끌 수 없다.
- 일일 요약(NTF-15)은 앱이 살아 있는지 확인하는 신호라서, 정보 등급을 꺼도 항상 보낸다(디스코드 알림을 켠 경우).
- 일일 요약 시각을 바꿀 수 있다(기본 09:00).
- 설정 화면에 "테스트 알림 보내기" 버튼을 둔다.
