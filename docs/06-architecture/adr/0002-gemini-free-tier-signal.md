# ADR-0002 시그널은 Gemini API 무료 등급

상태: 대체됨(D-108, 2026-11-09) · 처음 확정 2026-11-03

> **D-108(2026-11-09)로 LLM 시그널은 Gemini가 아니라 매매 PC의 Claude Code CLI 세션이 낸다.** 이 ADR의 본문은 기록이다. 새 시그널 결정은 [분석 보고서 세션 제안서](../../03-functional/analysis-report-session.md) 12장의 질문에 답을 받은 뒤 새 ADR로 쓴다(웹 검색 D-112, 매수 근거 D-114 포함).

## 맥락

- 사용자는 Claude, Gemini, ChatGPT 같은 LLM의 무료 버전으로 시그널을 평가하길 원했다.
- 무료 채팅 앱(claude.ai, ChatGPT, Gemini 앱)은 프로그램이 자동으로 부를 공식 방법이 없다. 브라우저 자동 조작은 각 서비스 약관에 어긋날 소지가 있다(Anthropic 소비자 약관은 API 키 외 자동화된 접근을 금지).
- 공식 API 중 무료로 쓸 수 있는 것은 Gemini API 무료 등급이다. 한국에서 쓸 수 있다.

## 결정

Gemini API 무료 등급을 쓴다. 모델 ID는 설정값으로 두고, 실패는 모두 중립(매수 안 함)으로 처리한다. 상세는 [LLM 시그널 명세](../../05-integration/llm-signal.md).

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 유료 API(Claude, OpenAI, Gemini 유료) | 이 사용량이면 월 1~4달러 수준. 무료 한도가 부족하면 전환 후보 |
| PC 로컬 모델(Ollama) | 무료·외부 전송 없음. PC 사양에 따라 속도·품질 차이가 큼 |
| Max 구독 + Claude Code 호출 | 약관상 허용 여부를 먼저 확인해야 하고 구독 사용량을 같이 씀 |
| 무료 채팅 앱 브라우저 자동화 | 약관 위반 소지. 기각 |

## 결과

- 무료 등급 입력은 Google 제품 개선에 쓰이고 사람이 검토할 수 있다. 공개 시세와 지표 요약만 보낸다(뉴스는 D-097로 수집하지 않는다).
- 무료 한도는 공개되지 않고 바뀔 수 있다. 한도 초과는 중립으로 처리하고 알린다.
- 모델이 폐기되거나 다른 모델로 넘겨질 수 있다. 응답 모델을 기록하고 설정에서 바꿀 수 있게 한다.
- 약관상 금융 자문으로 의존하면 안 되므로, 시그널은 여러 입력 중 하나로만 쓴다(ADR-0003).
