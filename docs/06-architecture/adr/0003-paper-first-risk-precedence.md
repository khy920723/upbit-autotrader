# ADR-0003 페이퍼 우선, 위험 관리 우선

상태: 확정 · 2026-11-03

## 맥락

- 어떤 로직도 수익을 보장할 수 없다. 사용자의 목표는 손해를 최소로 하는 것이다.
- LLM 출력은 매번 달라질 수 있고, 형식은 맞아도 내용이 틀릴 수 있다.
- 업비트에는 테스트넷이 없다.
- LLM 시그널은 과거 데이터로 백테스트하면 성과가 부풀려진다(look-ahead bias).

## 결정

- 기본 모드는 paper다.
- 위험 관리는 주문 직전의 마지막 관문이고, LLM이나 규칙 결과와 상관없이 항상 적용한다. 우회 옵션은 만들지 않는다.
- 페이퍼 인정일 28일과 체크리스트 A를 지나야 실전 점검(live-validate)으로 넘어갈 수 있다.
- 실전 점검은 업비트 주문 검증 API로 주문을 보내고 가상 체결로 포지션을 유지한다. 3일 이상 운영하고 체크리스트 B와 확인 문구를 거쳐 live로 바꾼다.
- live에서 paper로 돌아갈 때 실제 보유분을 관리 없이 남기지 않는다.

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 바로 소액 실전 | 버그가 실제 손실로 이어짐. 기각 |
| 페이퍼 2주 | 기록이 적음. 사용자가 4주를 선택 |
| LLM 단독 매매 | 판단이 흔들리면 그대로 매매가 됨. 사용자가 LLM + 규칙 확인을 선택 |

## 결과

- 실전까지 최소 4주가 걸린다.
- 모든 주문은 위험 검사를 통과해야 한다. 이 경로를 테스트로 증명한다.
- 페이퍼 손익에는 수수료, 슬리피지, 최소 주문 금액을 반영해 실전과의 차이를 줄인다.
