# ADR-0005 뉴스 출처: 네이버 검색 API + 영어 RSS

상태: 확정 · 2026-11-03 · 2026-11-07 약관 확인 결과 출처 재검토 대기(D-095~D-097)

## 맥락

- LLM은 현재 뉴스를 스스로 알지 못한다. 앱이 제목을 모아 전달해야 한다.
- 무료이고 약관상 자동 수집이 허용된 출처가 필요하다.

## 결정

- 한국어: 네이버 검색 API(뉴스, 하루 25,000회 무료).
- 영어: CoinDesk, Cointelegraph RSS.
- 제목, 링크, 출처, 시각만 저장하고 LLM에 보낸다. 상세는 [뉴스 수집 명세](../../05-integration/news-collection.md).

## 검토한 대안

| 대안 | 판단 |
|---|---|
| Google 뉴스 RSS | 피드 안내문이 개인 피드 리더 용도로 제한. 기각 |
| CryptoPanic API | 무료 플랜 없음(2026-11). 기각 |
| Gemini Google 검색 연동 | 무료 등급에서 불가, 검색 제안 표시 의무와 결과 분석 금지 조항. 기각 |
| 웹 크롤링 | 약관·robots.txt 위반 소지. 기각 |

## 결과

- 사용자가 네이버 개발자센터에서 앱을 등록하고 키를 마법사에 넣어야 한다.
- 약관 확인(2026-11-07): 네이버 검색 API 특약 2.3은 검색 결과를 AI에 입력하는 행위와 정한 기간을 넘는 저장을 금지하고, 개발자센터의 검색 API 신규 신청은 2026-07-30에 끝났다. Cointelegraph 약관 3절은 서면 동의 없는 LLM 이용을 금지한다. CoinDesk 약관은 읽지 못했다. 출처를 어떻게 할지는 D-095~D-097(대기)에서 정하고([4단계 시작 전 결정 묶음](../../03-functional/stage4-decisions.md) 3장), 이 ADR은 사용자 결정 뒤에 고친다.
