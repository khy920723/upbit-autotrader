# ADR-0005 뉴스 출처: 뉴스를 수집하지 않는다(약관)

상태: 확정(개정) · 2026-11-07 · 사용자 결정 D-095·D-096·D-097. 처음 결정(2026-11-03, D-013: 네이버 검색 API + CoinDesk·Cointelegraph RSS)은 D-097로 대체했다

## 맥락

- LLM은 현재 뉴스를 스스로 알지 못한다. 처음 결정(2026-11-03)은 앱이 뉴스 제목을 모아 LLM에 전달하기로 했다.
- 2026-11-07 약관 확인 결과([4단계 시작 전 결정 묶음](../../03-functional/stage4-decisions.md) 3장):
  - 네이버 검색 API: 검색 결과를 AI에 입력하는 행위와 정해진 목적·기간을 넘는 저장을 금지한다. 개발자센터의 신규 신청은 2026-07-30에 끝났다.
  - Cointelegraph: 서면 동의 없는 AI·LLM 이용(학습, 운영 등)과 자동 스크래핑을 금지한다.
  - CoinDesk: AI·RSS 조항은 없고, 자동 수단 접근 금지(서면 허락 필요)와 개인·정보·비상업 목적 한정 조항이 있다(지휘 세션 확인).
  - 대안도 쓸 수 없다(지휘 세션 확인): 네이버 검색 스크래핑, 구글 검색, Custom Search JSON API, Google 뉴스 RSS. 약관과 robots.txt가 막는다. Gemini의 Google 검색 그라운딩은 무료 등급에서 쓸 수 없다.
- 사용자 요구(2026-11-07): "일반적으로 제미나이나 코덱스 사용 시, 검색 시점을 기준으로 '특정 코인명'에 대한 긍정 시그널과 부정 시그널을 퍼센티지로 대략 유추해줘로 질문했을 때의 대답 정도만 있으면 됨. 뉴스까지 검색하지 않아도 됨."

## 결정

- 뉴스를 수집하지 않는다. LLM 입력은 시세·지표 요약만이다(D-097).
- 네이버 검색 API는 뺐다(D-095). 스크래핑과 구글 검색 대체도 쓰지 않는다.
- Cointelegraph RSS는 뺐다(D-096).
- CoinDesk는 사용자가 "본인 판단으로 쓴다"고 답했지만(C-1), D-097에 따라 지금은 쓰지 않는다. 판단은 나중을 위해 기록만 남긴다.

## 다시 넣을 때의 조건

- 약관이 LLM 입력과 저장을 명시적으로 허락하는 출처, 또는 서면 허락을 받은 출처만 쓴다.
- 공식 API나 RSS만 쓴다. 스크래핑과 robots.txt가 막는 수집은 하지 않는다.
- 새 결정 번호로 결정 로그에 먼저 기록하고, 이 ADR과 [뉴스 수집 명세](../../05-integration/news-collection.md)를 고친다.
- 그때 뉴스 수집 명세의 이전 설계(정리 규칙, 인젝션 방어, 저장 테이블, 가짜 뉴스)를 다시 검토한다.

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 네이버 검색 API(처음 결정) | 특약 2.3(AI 입력·저장 금지), 개발자센터 신규 신청 종료. 기각(D-095) |
| 네이버 검색 스크래핑 | 서비스 이용약관(허락 없는 봇 검색 금지), robots.txt, 검색결과 수집 정책. 기각(D-095) |
| 구글 검색, Custom Search JSON API, Google 뉴스 RSS | robots.txt와 약관이 자동 접근을 막는다. Custom Search JSON API는 신규 고객을 받지 않고 저장과 자동 질의를 제한한다. Google 뉴스 RSS는 개인 피드 리더 표시 외 용도를 금지한다. 기각(D-095) |
| Gemini Google 검색 그라운딩 | 무료 등급에서 쓸 수 없다. 약관이 결과의 분석·저장을 제한한다. 도구 호출 금지 규칙과 부딪친다. 기각 |
| Cointelegraph RSS(처음 결정) | 약관 3절이 AI·LLM 이용과 자동 스크래핑을 금지한다. 기각(D-096) |
| CoinDesk RSS만 | 사용자는 써도 된다고 판단했다(C-1). 뉴스 없이 가기로 해(D-097) 지금은 쓰지 않는다 |
| CryptoPanic API | 무료 플랜 없음(2026-11). 기각 |
| 웹 크롤링 | 약관·robots.txt 위반 소지. 기각 |

## 결과

- 4단계에서 다음을 만들지 않는다.
  - 뉴스 수집과 FakeNews
  - `news_items`·`signal_news` 테이블
  - 네이버 키(마법사 W4, keyring)와 뉴스 설정
- 모델은 검색 없이 앱이 보낸 시세·지표와 학습 시점까지의 일반 지식으로만 답한다. 그래서 프롬프트는 받은 데이터만 근거로 쓰고 최근 뉴스나 사건을 아는 것처럼 말하지 않게 한다(D-100, [LLM 시그널 명세](../../05-integration/llm-signal.md)).
- 이전 설계는 [뉴스 수집 명세](../../05-integration/news-collection.md)에 기록으로 남긴다.
