# ADR-0008 매수·매도 분할: 매수 최대 2단계(2단계는 평균 단가보다 내렸을 때), 익절만 최대 2단계

상태: 확정 · 2026-11-05 · 사용자 결정(D-082, D-083, D-084, D-085, D-043). 2단계 하락률 기본값(D-086)은 대기. 이전 제안(기본 한 번에 + 균등 2~3회, D-039)은 D-082로 대체했다

## 맥락

- 코인마다 포지션은 하나다. 매수 조건은 LLM 긍정 + 규칙 조건 + 위험 한도다([매매 로직 명세](../../03-functional/trading-logic.md) 2장, D-006).
- 업비트 KRW 마켓 최소 주문 금액은 5,000원이다. 앱은 `/v1/orders/chance`의 `min_total`로 읽는다(2026-11-05 확인, [업비트 API 연동 명세](../../05-integration/upbit-api.md)). 키 없이 paper로 운영할 때는 이 API를 부를 수 없어 공식 문서 값 5,000원을 추정값으로 쓰고, 키를 넣으면 예산 하한을 다시 검사한다(D-059 대기).
- 손절 시점에도 팔 수 있으려면 보유 금액이 손절 폭만큼 줄어든 뒤에도 최소 주문 금액 이상이어야 한다. 그래서 [위험 관리 정책서](../../03-functional/risk-policy.md)는 **예산 하한 = 최소 주문 금액 ÷ (1 − 손절%/100) × 1.1**을 둔다. 1.1은 위험 관리 정책서 2장이 정한 여유 계수다.
- 기본 설정(코인별 예산 10,000원, 손절 5%)에서 예산 하한은 5,000 ÷ 0.95 × 1.1 = 약 5,790원이다.
- 분할 매수에서는 1단계만 산 상태에서도 손절할 수 있어야 하므로, 하한은 **단계 금액**에 적용한다.

| 손절 % | 예산 하한(단계당, 원 단위 올림) | 매수 2단계 50/50 최소 예산 |
|---|---|---|
| 3 | 5,671원 | 11,342원 |
| 5(기본) | 5,790원 | 11,580원 |
| 10 | 6,112원 | 12,224원 |

(최소 주문 금액 5,000원 기준. 단계 금액은 원 단위로 내림한다. 실제 값은 앱이 `min_total`로 다시 계산한다.)

- 기본 예산 10,000원에서는 50/50 단계 금액이 5,000원이 되어 하한보다 작다. **기본 설정으로는 나눠 살 수 없다.**
- 사용자 요청(2026-11-05): 분할 매수·매도 알고리즘을 다시 설계하고, 몇 단계로 몇 퍼센트씩 나눌지는 사용자에게 입력받는다.

## 결정

**매수는 최대 2단계, 익절은 최대 2단계로 사용자가 비율을 입력해 나눈다. 2단계 매수는 시그널 평가 때 매수 조건을 다시 모두 만족하고 현재가가 평균 단가보다 하락률 이상 낮을 때만 한다. 손절과 그 밖의 매도는 전량이다.** 자세한 규칙은 [분할 매수·매도 설계](../../03-functional/split-trading.md)에 있다.

1. **입력(D-082, D-083):** `buy.step_pcts`(1~2단계, 1% 단위 정수, 합 100, 기본 `[100]`), `buy.next_step_drop_pct`(2단계 하락률, 0 < 하락률 < 손절%), `sell.take_profit_steps`(0~2단계, 발동 수익률과 매도 비율). 기본값이면 한 번에 사고 익절은 꺼져 있다.
2. **저장 검사:** 비율 합, 단계 수 상한, 단계 금액 ≥ 예산 하한, 익절 뒤 남는 원가 ≥ 예산 하한, 하루 주문 수, 주문 간격, 하락률 범위(설계 3.2의 S1~S7). 못 맞추면 저장하지 않고 필요한 코인별 예산과 가능한 최대 단계 수를 보인다.
3. **2단계(D-084):** 보유 중 시그널 평가에서 매수 조건 6개를 다시 모두 만족하고 현재가 ≤ 평균 단가 × (1 − 하락률/100)이면 2단계 하나를 산다. 시그널 없이 가격만으로 사지 않는다. 체결되지 않으면 다음 평가에서 다시 본다.
4. **분할 매도(D-085):** 익절만 나눠 판다. 손절, 정지 후 전량 매도, 규칙상 청산, LLM 부정 매도, 선택 해제 매도, 모드 전환 매도, exit_only 실보유분은 전량이다. 나눠 판 뒤 남는 수량을 손절선 가격으로 평가한 금액이 매도 최소 주문 금액 × 1.1보다 작거나 그 단계 매도분이 매도 최소 주문 금액보다 작으면 그 단계에서 전량 판다. 첫 익절 뒤에는 더 사지 않는다.
5. **계획 고정:** 포지션을 열 때 단계 계획을 저장하고 FLAT이 될 때까지 쓴다. 설정을 바꾸면 다음 포지션부터 적용한다. 위험 한도는 언제나 지금 설정으로 검사한다.
6. **금액과 손절:** 단계 금액은 상한이고 승인 금액은 지금 식으로 줄 수 있다. 1단계는 예산 하한(D-067), 2단계는 매수 최소 주문 금액을 본다. 매수 체결마다 평균 단가를 다시 계산하고 손절선·익절 발동 가격도 바뀐다.
7. **주문 유형(D-043):** 매수 단계는 최유리 FOK, 매도(익절 단계 포함)는 시장가. 페이퍼는 호가로 체결을 계산한다.

## 검토한 대안

| 대안 | 장점 | 단점 | 판단 |
|---|---|---|---|
| 한 번에만(분할 없음) | 가장 단순하다. 주문 수가 적다 | 사용자 요청(단계·비율 입력)과 맞지 않는다 | 기각(D-082 C). 기본값으로는 지금도 한 번에 산다 |
| 균등 2~3회, 다음 회차는 새 긍정 시그널, 매도 전량(이전 제안) | 입력이 적다 | 비율 입력과 분할 익절이 없다 | 기각(D-082 B, D-039 대체) |
| 2단계를 새 긍정 시그널만으로 | 추가 입력이 없다 | 사용자가 하락 조건을 골랐다 | 기각(D-084 A) |
| 2단계를 평균 단가보다 올랐을 때(상승) | 이익 중인 포지션에만 더 산다 | 손절선이 올라가 작은 되돌림에 전체가 손절될 수 있고, 예산이 평가액 기준이라 계획보다 덜 산다 | 기각(D-084 C) |
| 2단계를 시간 간격으로 | 매수 간격이 넓어진다 | 가격과 상관없이 노출이 는다 | 기각(D-084 D) |
| 같은 평가 안에서 시간 간격을 두고 나눠 주문 | 한 번에 큰 주문을 내지 않는다 | 이 주문 크기에서는 체결 가격 이점이 거의 없고 주문 수만 는다. 짧은 간격의 소액 반복 주문은 피한다는 원칙([위험 관리 정책서](../../03-functional/risk-policy.md) 7장)과 맞지 않는다 | 기각 |
| 손절도 나눠 팔기 | 손절 직후 반등하면 일부를 남긴다 | 코인별 손실이 손절%를 넘을 수 있고, 손실을 줄이는 매도를 막지 않는다는 원칙 2와 맞지 않는다 | 기각(D-085 C) |
| 단계 수 상한 3·2, 4·2, 5·3 | 더 잘게 나눌 수 있다 | 주문 수가 늘고 필요한 예산이 커진다 | 기각(D-083, 사용자가 2·2를 골랐다) |

- 2단계 하락 조건의 위험: 손실 중인 포지션에 돈이 더 들어가고, 평균 단가와 손절선이 내려가 손절이 첫 매수가보다 더 낮은 가격에서 일어난다(50/50, 하락률 2%, 손절 5%면 첫 매수가 대비 약 5.96%). 사용자가 이 위험을 보고 골랐고, 설정 화면에 늘 안내한다(MSG-W013). 이를 줄이는 장치는 하락률 < 손절%, 매수 조건 재충족, 단계 수 상한 2, 코인별 예산 상한이다. 코인별 손실 금액은 손절선에서 팔 때 "산 금액 전체 × 손절%" 근처로 묶인다(수수료·슬리피지 제외).

## 결과

- 설정 항목: `buy.step_pcts`, `buy.next_step_drop_pct`, `sell.take_profit_steps`([설정 항목 정의서](../../03-functional/settings.md)). 이전의 `buy.method`, `buy.split_count`, `risk.take_profit_pct`는 쓰지 않는다.
- 데이터: positions의 `entries`(매수 단계 수), `plan_json`(단계 계획), `tp_steps_done`, `tp_base_volume`, orders의 `step_no`, round_trips의 `entries`, `tp_steps`([데이터 모델](../../04-data/data-model.md)).
- 일일 주문 수: 코인당 한 사이클 최대 4건(매수 2 + 익절 2), 코인 3개면 12건. 기본 상한 20건 안이다.
- 문구: MSG-E015(예산 부족), MSG-E020(단계 계획 저장 거부), MSG-W013(2단계 위험 안내), MSG-I010(다음 포지션부터 적용).
- 테스트: TS-60~TS-62, TS-92, TS-138, TS-146~TS-152, INV-01, INV-20.
- 2단계 하락률의 기본값은 D-086에서 정한다. 정하기 전에는 기본값 없이 입력을 받는다.
- 어떤 방식이 수익을 내는지는 판단하지 않는다. 페이퍼 운영 기록을 보고 사용자가 바꿀 수 있다.
