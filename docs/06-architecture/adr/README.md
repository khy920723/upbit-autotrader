# 아키텍처 결정 기록(ADR)

중요한 기술 결정을 하나씩 파일로 남긴다. 결정이 바뀌면 기존 파일을 고치지 않고, 새 ADR을 만들어 이전 것을 "대체됨"으로 표시한다.

## 형식

```text
# ADR-NNNN 제목
상태: 제안 | 확정 | 대체됨(ADR-XXXX) · 날짜
## 맥락
## 결정
## 검토한 대안
## 확인한 사실(선택: 결정 근거로 확인한 외부 사실과 출처)
## 결과
## 결정이 필요한 것(제안 상태에서만)
```

## 결정 대기

- "제안" ADR은 사용자가 승인하면 "확정"으로 바꾸고 [결정 로그](../../10-management/decision-log.md)의 해당 항목 상태를 "유효"로 바꾼다.
- 제안 상태에서 사용자가 추천과 다른 대안을 고르면 같은 파일의 제목·결정·결과를 그 대안으로 고친 뒤 "확정"으로 바꾼다. 위의 "새 ADR을 만들어 대체" 규칙은 확정된 ADR에만 적용한다.
- 0007(규칙 조건)은 처음에는 [규칙 조건 후보 비교 리포트](../../research/rule-candidates.md)를 보고 사용자가 고른 뒤 쓰기로 했다(D-072, D-073). D-107·D-114로 바뀌어 제안서 답 뒤에 다룬다.
