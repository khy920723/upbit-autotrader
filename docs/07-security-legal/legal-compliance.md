# 법·약관·라이선스 검토

상태: 초안(일부 미확인) · 2026-11-03 조사 · 이 문서는 법률 자문이 아니다.

## 1. 사용 범위

- 개인이 본인 업비트 계정과 본인 자금으로 쓰는 앱이다.
- 다른 사람의 자금 운용, 앱 판매·대여, 시그널 제공은 하지 않는다. 이런 경우에는 별도 규제 문제가 생길 수 있다.

## 2. 가상자산 이용자 보호 등에 관한 법률

- 2024-07-19 시행. 시세조종, 부정거래, 미공개중요정보 이용을 금지한다.
- 처벌(금융위원회 안내): 1년 이상 징역 또는 부당이득의 3~5배 벌금. 부당이득 규모에 따라 가중되고, 부당이득의 2배 과징금도 있다.
- 거래소는 이상 거래를 상시 감시하고 의심 사례를 보고해야 한다.
- 2025-11-05 금융위원회는 API로 초당 여러 번 소액 매수·매도를 수십 분간 반복해 거래량을 부풀린 사례를 수사 기관에 넘겼다. 짧은 시간의 과도한 반복 주문은 API 주문이라도 시세조종이 될 수 있다고 경고했다.
- 앱의 대응은 [위험 관리 정책서](../03-functional/risk-policy.md) 7장(자기체결 방지, 주문 간격, 일일 주문 수 상한, 기록).
- 미확인: 조문 원문(law.go.kr 조회 실패). 개인이 본인 계정으로 봇을 쓸 때 등록 의무가 있다는 근거는 찾지 못했지만, 없다고 명시한 1차 자료도 찾지 못했다. 공유·판매를 검토하게 되면 금융위원회와 업비트에 확인한다.

## 3. 업비트

- 확인됨: 요청 한도를 반복해서 넘기면 418로 차단되고 차단 시간이 늘어난다. upbit.com의 robots.txt는 모든 자동 수집을 막는다.
- 미확인: Open API 이용약관 전문(https://upbit.com/open_api_agreement, 페이지가 스크립트로 그려져 읽지 못함). 실전 전환 전에 업비트 계정에서 직접 확인한다.
- 확인됨(2026-11-05): 업비트 개발자 센터의 "업비트 개발자 SDK 라이센스 v1.0"(docs.upbit.com/kr/page/upbit_developer_sdk_license, 2026-01-07 갱신)은 두나무가 공개하는 소프트웨어, 스크립트, 소스코드, 구성 파일과 "이에 포함된 문서 일체"에 적용된다고 밝힌다. 오픈소스 라이선스가 아니며, 개인 목적 사용만 허용하고, 수정·재배포는 라이선스 전문을 넣고 전체 소스를 공개할 때만 허용하며, 사업·수익 목적 사용을 금지한다.
- 그래서 이 저장소(MIT)에는 업비트 문서의 예제 코드나 SDK 코드를 그대로 복사하지 않는다. 공식 문서의 명세(엔드포인트, 필드, 규칙)를 보고 직접 구현한다. 공식 Python SDK 저장소의 라이선스 표기는 Apache-2.0이라 위 라이선스와의 관계가 불분명하다(확인 필요, 문의처 open-api@upbit.com). ADR-0006(확정, D-038)에 따라 자체 클라이언트를 만들고 SDK는 의존성으로 넣지 않는다.

## 4. Gemini API (추가 약관 2026-03-23 시행)

- 무료 등급 입력과 출력은 Google 제품 개선에 쓰이고 사람이 검토할 수 있다. 민감·기밀·개인 정보를 보내면 안 된다.
- 18세 이상, 지원 지역에서만 이용. 한국은 지원 지역이다.
- 금융 자문으로 의존하면 안 된다. 그래서 앱은 시그널을 여러 입력 중 하나로만 쓰고 위험 관리는 코드가 강제한다.
- Google 검색 연동 결과에는 표시 의무와 분석 금지 조항이 있다. 쓰지 않는다.
- 미확인(사용자 판단): 추가 약관에 "Use of Google AI Studio and Gemini API is for developers building with Google AI models for professional or business purposes, not for consumer use."라는 문장이 있다(aistudio.google.com/docs/terms, 2026-11-05 확인). 본인이 만들어 본인만 쓰는 앱에 이 문장이 어떻게 적용되는지는 법 해석 문제다. 4단계 전에 사용자가 확인한다.
- 무료 등급 입력·출력은 계정·키·프로젝트와 분리한 뒤 사람이 읽고 주석을 달 수 있다. EEA·스위스·영국 사용자에게 제공하는 앱은 유료 서비스만 써야 한다(이 앱은 해당 없음).

## 5. 무료 채팅 앱 자동화

- Anthropic 소비자 약관(2025-10-08 시행): API 키를 쓰거나 명시적으로 허용된 경우가 아니면 봇·스크립트 같은 자동화된 수단으로 접근할 수 없다.
- Google 서비스 약관(2026-07-30 시행): robots.txt 같은 기계 판독 지침을 어기는 자동화 접근을 금지한다.
- OpenAI 이용약관: 원문 확인 실패(403). 검색 결과로는 출력의 자동·프로그램 추출을 금지한다. 이 앱은 쓰지 않으므로 영향이 없다.

## 6. 뉴스

- 네이버 검색 API: 하루 25,000회 무료. 미확인: 결과 저장과 제3자 서비스(Gemini) 전달 조건. 4단계 전에 developers.naver.com 이용약관을 확인한다.
- RSS: 제목·링크만 쓰고 출처를 표시한다. 본문은 저장하지 않는다.
- Google 뉴스 RSS는 피드 안내문이 개인 피드 리더 용도로 제한해 쓰지 않는다.

## 7. 세금 기록

- 현행법상 가상자산 소득 과세는 2027-01-01 시행 예정이다(2026-11 기준). 추가 유예 법안이 논의 중이라 바뀔 수 있다.
- 앱은 모든 체결·수수료·원화 금액·시각을 기록하고 CSV로 내보낸다. 2026-12-31 기준 보유 현황 스냅샷을 남겨 두면 취득가액 계산에 도움이 될 수 있다. 세부는 세무 전문가에게 확인한다.
