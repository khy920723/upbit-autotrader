# 설치·초기 설정 가이드

상태: 초안(앱 완성 후 화면에 맞게 보완) · 대상: Windows 10 22H2 64비트 데스크톱 · 관련: [보안 정책](../07-security-legal/security-policy.md), [운영 런북](runbook.md)

## 1. Windows 설정

| 항목 | 방법 |
|---|---|
| 버전 확인 | 설정 → 시스템 → 정보 → Windows 사양에서 버전 22H2 확인 |

### 자동 로그인

재부팅 후 사람 없이 매매를 재개하려면 필요하다. 이 절의 작업(Autologon, BitLocker)은 관리자 권한이 필요하다.

지금 쓰는 Windows 계정을 그대로 자동 로그인한다(결정 로그 D-033). 이 계정이 관리자라면 PC를 만지는 사람이 관리자 권한까지 얻을 수 있으므로, 아래 "로그인 직후 화면 잠금"을 반드시 설정한다. 계정 암호는 다른 서비스와 같이 쓰지 않는다.

1. Microsoft 공식 도구 Sysinternals Autologon을 마우스 오른쪽 클릭 → 관리자 권한으로 실행한다.
2. 사용자 이름과 암호를 넣고 켠다. Microsoft 계정이면 사용자 이름에 이메일을 넣고, 설정 → 계정 → 로그인 옵션의 "Microsoft 계정에 Windows Hello 로그인 필요"를 끈다.
3. 이 암호는 Windows에 LSA 비밀로 저장되며 관리자 권한이 있으면 꺼낼 수 있다.
4. 부팅할 때 Shift를 누르고 있으면 자동 로그인을 건너뛴다.

### 로그인 직후 화면 잠금 (필수)

자동 로그인 뒤 앱은 계속 돌고 화면만 잠기게 한다.

1. 작업 스케줄러 → 기본 작업 만들기 → 트리거 "로그온할 때".
2. 동작 "프로그램 시작": 프로그램 `rundll32.exe`, 인수 `user32.dll,LockWorkStation`.

## 2. 계정과 키 준비

### 업비트

1. 본인 인증과 2채널 인증을 마친다.
2. 실전 전에: 봇 전용 서브 포켓을 만들고 감당할 수 있는 금액만 옮긴다.
3. 업비트 PC 웹 → Open API 관리에서 **봇 전용 서브 포켓의** 키를 발급한다. 기본 포켓 키를 쓰면 계정 전체 잔고가 노출 범위가 된다. paper 단계에서 다른 키를 넣었다면 실전 점검 전에 서브 포켓 키로 바꾼다.
   - 권한: 자산조회, 주문조회, 주문하기만 체크한다. 출금·입금은 체크하지 않는다.
   - 허용 IP: 매매 PC의 공인 IPv4. 인터넷에서 "내 IP 확인"으로 찾는다.
   - Secret Key는 발급 화면에서 한 번만 보인다. 바로 마법사에 넣거나 안전한 곳에 잠깐 적어 둔다.
   - 발급일을 메모한다(1년 뒤 만료).
4. 집 IP가 고정인지 확인한다: 공유기를 재부팅하기 전과 후의 공인 IP를 비교하거나 통신사에 묻는다. 바뀌면 유동 IP다.
5. paper 모드는 키 없이도 시작할 수 있다(마법사에서 "나중에 입력").

### Gemini

1. aistudio.google.com에 Google 계정으로 들어가 API 키를 만든다.
2. AI Studio에서 쓸 모델의 무료 한도를 확인한다.

### 네이버 검색 API

1. developers.naver.com → Application → 애플리케이션 등록.
2. 사용 API에서 "검색"을 고르고 Client ID와 Client Secret을 받는다.

### 텔레그램 (선택)

1. BotFather에서 `/newbot`으로 봇을 만들고 토큰을 받는다.
2. 만든 봇에게 `/start`를 보낸다.

## 3. 설치

1. GitHub Actions에서 받은 zip을 마우스 오른쪽 클릭 → 속성 → "차단 해제" 체크 → 확인.
2. `C:\Apps\upbit-autotrader\`처럼 쓰기 권한이 있는 폴더에 압축을 푼다(Program Files는 피한다).
3. `autotrader.exe`를 실행한다. SmartScreen 경고가 뜨면 "추가 정보 → 실행".
4. Defender가 격리하면: Windows 보안 → 바이러스 및 위협 방지 → 보호 기록에서 복원하고, Microsoft에 오탐으로 제출한다.

### 자가 점검

설치한 폴더에서 실행 환경을 점검한다. 창을 띄우지 않고, 네트워크와 키를 쓰지 않는다.

1. 압축을 푼 폴더의 빈 곳에서 Shift + 마우스 오른쪽 클릭 → "여기에 PowerShell 창 열기".
2. 아래 명령을 실행한다(끝날 때까지 몇 초 기다린다).

```powershell
Start-Process -FilePath .\autotrader.exe -ArgumentList '--self-test' -WorkingDirectory $PWD -Wait
```

3. 같은 폴더에 생긴 `self-test-report.txt`를 메모장으로 열어 마지막 줄이 `결과: 통과 (6/6)`인지 본다. 실패한 항목은 `[실패]`로 표시되고 원인이 적힌다.
4. 2단계 빌드에서는 `autotrader.exe`를 두 번 클릭하면 "업비트 자동매매 0.0.1" 빈 창이 뜨고, 창을 닫으면 끝난다.
