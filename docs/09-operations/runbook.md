## 1. 정기 점검

| 주기 | 할 일 |
|---|---|
| 매일 | 09:00 일일 요약 확인. 안 오면 2장의 "일일 요약이 안 옴" |
| 매주 | 대시보드 이벤트 로그 훑어보기, 차단·실패가 늘었는지 확인 |
| 매월 | 새 버전 확인, Windows 업데이트를 사용 시간 밖에 직접 적용, 키 만료일과 ESU 상태 확인 |

## 2. 상황별 대응

| 증상 | 원인 | 조치 |
|---|---|---|
| 긴급 알림: 허용 IP 오류(MSG-E001) | 집 공인 IP가 바뀜 | 업비트 PC 웹 → Open API 관리에서 알림에 나온 IP 추가(최대 10개, 안 쓰는 IP는 정리) → 앱에서 [다시 점검]. 그동안 보유 코인은 업비트 앱에서 직접 판단 |
| 키 만료 예고·만료(MSG-W004, E002) | 1년 유효기간 | 새 키 발급(권한 3개, 허용 IP) → 설정 → 계정·키 → 입력 → 이전 키 삭제 |
| 418 차단(MSG-E004) | 요청 한도 반복 초과 | 앱이 차단 시간 동안 기다린 뒤 다시 점검. 반복되면 가린 진단 묶음과 함께 이슈 등록 |
| Gemini 한도 초과(MSG-E006) | 무료 한도 소진 | KST 16~17시 초기화까지 중립 처리. 자주 나면 평가 주기 늘리기, 모델 바꾸기, 유료 전환 검토 |
| 응답 모델 변경(MSG-W007) | 모델 폐기·재라우팅 | AI Studio 공지 확인 → 설정에서 모델 ID 변경 |
| 시세 끊김, 네트워크 끊김(MSG-E011, E008) | 인터넷·업비트 장애 | 공유기·인터넷 확인. 앱이 자동으로 다시 연결 |
| 시계 오차(MSG-E010) | PC 시계 틀어짐 | Windows 시간 "지금 동기화" |
| 일일 요약이 안 옴 | PC 꺼짐, 앱 멈춤, Defender 격리 | PC 켜짐·로그인 확인 → 트레이 아이콘 확인 → 보호 기록 확인 → 앱 실행 |
| 시작 점검 실패 | 항목별 | 시작 점검 화면(SCR-07)의 안내대로 |
| 유의·주의·거래지원 종료 알림(MSG-W001, W002) | 업비트 지정 | 업비트 공지 확인 → 보유분 처리 결정 → 필요하면 코인 교체 |
| 주문 결과 불명이 오래 감(MSG-E014) | 거래소 응답 지연·장애 | 업비트 앱에서 주문 내역 확인. 앱은 계속 조회. 필요하면 앱을 다시 시작(시작 점검이 거래소 기준으로 맞춤) |
| 앱이 갑자기 꺼짐 | 버그, OS 문제 | 다시 실행하면 시작 점검이 거래소 기준으로 대조. 로그 확인 후 이슈 등록 |
| 급변동 등 긴급 상황 | - | [정지] 또는 [정지 후 전량 매도] |
| Defender 격리 | 오탐 | 보호 기록에서 복원 → 앱 폴더를 제외 목록에 추가 → 오탐 제출 |
| DB 손상 | 디스크·강제 종료 | 앱 종료 → `backup\`의 최신 백업으로 교체 → 실행(거래소 기준으로 대조) |

## 3. 새 버전 설치

1. 대시보드에서 [정지](신규 주문 중지 + 미체결 취소, 보유는 유지).
2. 트레이 → 종료.
3. 기존 폴더를 `upbit-autotrader-old`로 이름을 바꾸고, 새 zip을 차단 해제한 뒤 **기존과 같은 경로**(예: `C:\Apps\upbit-autotrader\`)에 푼다. 시작 앱 등록이 이 경로를 가리키기 때문이다. 데이터는 `%LOCALAPPDATA%`에 있어 그대로 남는다.
4. 새 `autotrader.exe` 실행 → 시작 점검 → [시작].
5. 문제가 있으면 old 폴더로 되돌린다. DB 구조가 바뀐 버전이었다면 `backup\`에서 이전 DB를 복원한다.

## 4. 백업과 복원

- 앱이 하루 1회 DB를 백업하고 7개를 남긴다(`%LOCALAPPDATA%\upbit-autotrader\backup\`).
- 거래 기록은 거래 기록 화면에서 CSV로 따로 내보낼 수 있다.
- 복원: 앱 종료 → `data\`의 DB 파일과 같은 이름의 `-wal`, `-shm` 파일을 다른 곳으로 옮김 → 백업 파일을 `data\`로 복사 → 실행.
- live 계열은 시작 점검이 잔고·주문을 거래소 기준으로 다시 맞춘다. paper 기록, 시그널 기록, 페이퍼 인정일은 백업 시점으로 되돌아간다.
